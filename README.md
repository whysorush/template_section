# GrowthAlly — Financial Services Template (Next.js + Tailwind)

A production‑ready starter inspired by the layout/sections of **pinc.co.in**.
It **does not** copy their content or assets. Replace the placeholder text with your own.

## Quick Start
```bash
npm i
npm run dev
# open http://localhost:3000
```

## Colors (from your logo)
- Primary (Blue): `#2C4E91`
- Secondary (Green): `#4A8F2F`
- Brown: `#7A4E2E`
- Neutral Gray: `#5A5A5A`
- Background: `#FFFFFF`

## Structure
- Sticky header with deep blue background, white links, and green hover
- Hero banner with big headline + 4 service cards
- Services grid (4 cards with bullets & CTA)
- Why Choose Us (stats) + Select Transactions grid
- Testimonials
- About (Overview + Vision/Mission + Leadership list)
- Blog preview + News/Financial highlights
- Contact (Offices + Form)
- Footer with site links and legal
